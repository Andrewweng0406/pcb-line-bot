## Added While Away

- `scripts/compare_extraction_reports.py`: detects per-field regressions, improvements and newly false high confidence. It rejects changed evaluation populations and input bytes. Unchanged failures remain failures, even when aggregate accuracy has not declined.
- `scripts/check_backup_health.py`: checks supplied snapshots for integrity, age, timestamps and restrictive file permissions, plus optional persistent-file archive checksums. It does not restore, delete, schedule jobs or claim automated backups are enabled.
- Shared snapshot validation was separated from application/database imports. Backup health and report comparison now run with the standard library alone; the existing backup/restore interfaces remain available. Unknown snapshot versions and malformed IDs fail as explicit validation errors.
- Focused tests cover mixed improvements/regressions, incompatible reports, stale/tampered backups, missing/duplicate/traversal/symlink archive entries and restricted output permissions.
- Operational documentation contains exact commands and explicitly separates local file health, restore verification and provider scheduling.
